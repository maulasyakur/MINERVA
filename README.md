# MINERVA – Safe Space Journey for All

A space-themed website for the NASA Space Apps microgravity combustion challenge. It matches a fire
scenario for a spacecraft, Moon or Mars habitat against recorded NASA combustion test runs and
explains how the flame is likely to behave.

| Folder | Contents |
|--------|----------|
| `IGNIS website/` | The website: `index.html` (the only HTML file), `css/`, `js/`, `data/` and the data build script. See its README. |
| `dataset-psi/` | The NASA Physical Science Informatics (PSI) combustion tables and the merged CSV the site is built from. |

Open `IGNIS website/index.html` in a browser to use the site.
