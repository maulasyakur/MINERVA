Mission briefing · NASA Space Apps

How does fire behave beyond Earth?

Set up a fire scenario for a spacecraft cabin, a Moon base or a Mars habitat. Minerva searches the NASA Physical Science Informatics (PSI) combustion tables for runs under the most similar conditions, shows what was measured in them, and tells you plainly when your scenario lies outside anything that was tested.

Flight path

From scenario to evidence in five stages

  1. 01

    Set a scenario

    Environment, fuel, oxygen, pressure, airflow and flow direction.

  2. 02

    Match runs

    Nearest-neighbour search over the test runs, with each variable scaled by its spread in the data.

  3. 03

    Summarise outcomes

    What the closest runs recorded: extinction, ignition, burn time, spread rate.

  4. 04

    Explain

    Plain-language notes, each labelled as coming from the data or from physics.

  5. 05

    Rate confidence

    Based on how many runs sit close to your scenario, not on guesswork.

      What's in the data

      All figures on this page are computed from data/psi_data.js, which scripts/build_data.py builds from the merged PSI table. Each run card names its source file and row.

      PROTOTYPE Minerva retrieves and summarises recorded test runs; it does not simulate combustion or certify fire safety. Every run in the dataset was done in microgravity, so Moon, Mars and Earth readouts are extrapolations. Flame visuals are illustrative.

      Built for the NASA Space Apps challenge. Data: NASA Physical Science Informatics (PSI) experiment tables. Background reading: NASA Glenn combustion science.
